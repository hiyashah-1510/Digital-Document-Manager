# 📁 DocVault

### A Modern Dark-Theme Document Management Dashboard

Upload, organize, preview, categorize, and manage files —
all inside a beautiful **luxury-dark UI dashboard** built with React.

---

# ✨ Overview

**DocVault** is a modern **file management dashboard** that allows users to upload, organize, categorize, and manage documents in a clean and elegant interface.

It mimics the workflow of cloud storage platforms while running completely **in the browser** using local state management.

The project demonstrates real-world frontend architecture including:

* Scalable component structure
* Centralized state management
* Responsive UI
* Advanced filtering logic
* File preview rendering

---

# 🚀 Features

| Feature                  | Description                                 |
| ------------------------ | ------------------------------------------- |
| 📤 **File Upload**       | Upload any file directly from your device   |
| 🖼️ **Image Preview**    | Automatic preview for supported image files |
| ⭐ **Star Files**         | Mark important files as favorites           |
| 🗂️ **Categories**       | Organize files into categories              |
| 🕓 **Recent View**       | Quickly find recently uploaded files        |
| 🗑️ **Trash System**     | Soft delete and restore files               |

| 🎨 **Luxury Dark Theme** | Professional dashboard look                 |

# ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/docvault.git
```

Navigate to the project folder:

```bash
cd docvault
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the application in your browser:

```
http://localhost:5173
```

# 📌 State Management

The application uses **Redux Toolkit** to manage file data including:

* Upload files
* Star / unstar
* Delete / restore
* Categorization
* Filtering views

This ensures predictable state updates and scalable architecture.
